# IlyattoPC – интернет-магазин комплектующих для ПК

Web-приложение на Django и PostgreSQL.

## Что умеет
- **Покупатель**: смотрит каталог, ищет товары, собирает компьютер в конфигураторе, кладёт товары в корзину, оформляет заказ и видит свои заказы.
- **Сотрудник** (пользователь с галочкой `is_staff`): меняет статусы заказов, добавляет, изменяет и удаляет товары, смотрит отчёт о продажах и скачивает его в Excel.

В конфигураторе проверяются три правила совместимости: сокет процессора и платы, тип памяти (DDR4 или DDR5) у платы и ОЗУ, мощность блока питания (процессор + видеокарта + 100 Вт). Проверка находится в функции `check_build` в `shop/views.py`.

Корзина хранится в сессии Django. Когда заказ оформлен, товар списывается со склада. Если сотрудник отменил заказ, товар возвращается на склад.

## Как запустить
1. В pgAdmin создать пользователя `pcshop` и базу `pcshop`.
2. В файле `backend/config/settings.py` вписать свой пароль от базы (`PASSWORD`).
3. В терминале перейти в папку backend и выполнить:
```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py seed
python manage.py runserver
```
4. Открыть http://127.0.0.1:8000/, войти сотрудником и добавить товары в разделе «Товары».

### Через Docker
Нужен установленный Docker Desktop. База и сайт запускаются одной командой:
```bash
docker compose up --build
```
Таблицы и аккаунты создадутся сами. Остановить: Ctrl+C или `docker compose down`.

Аккаунты после `seed`:
- сотрудник: `admin` / `admin123`
- покупатель: `client` / `client123`

## Файлы проекта
```
backend/                         серверная часть (Python, Django)
  manage.py                      запуск команд Django
  requirements.txt               нужные библиотеки
  config/settings.py             настройки и подключение к базе
  config/urls.py                 главный файл адресов
  shop/models.py                 таблицы: Product (товар), Order (заказ), OrderItem (товар в заказе)
  shop/views.py                  вся логика страниц
  shop/urls.py                   адреса страниц
  shop/forms.py                  форма товара для сотрудника
  shop/admin.py                  таблицы в админке Django
  shop/management/commands/seed.py   создание аккаунтов сотрудника и покупателя

frontend/                        внешний вид сайта
  templates/base.html            общий шаблон: шапка и подключение стилей
  templates/shop/                страницы покупателя
  templates/staff/               страницы сотрудника
  static/app.css                 стили
  static/app.js                  маска телефона

Dockerfile                       как собрать контейнер с сайтом
docker-compose.yml               запуск базы и сайта вместе
```
